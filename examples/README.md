# Examples

This folder shows what the tool prints.

| File | Command used |
|------|--------------|
| `sample_output.txt` | `python3 -m linux_diagnostics` |
| `sample_output.json` | `python3 -m linux_diagnostics --json` |
| `save_report.sh` | A small Bash script that saves a JSON report with a date in the file name |

**Important:** the values in the sample files are **fake**. The hostname
`helpdesk-lab-vm` and all numbers were invented. They were generated by
running the real program with test data, so the format is exactly the same
as the real output.

Never commit a report from a real computer to a public repository without
checking it first. Use the `--redact` option to hide the hostname.

## Read the JSON with other tools

JSON output is useful because other programs can read it. Examples:

```bash
# Show only the memory usage percentage (needs the "jq" program)
python3 -m linux_diagnostics --json | jq '.memory.usage_percent'

# Same thing, using only Python
python3 -m linux_diagnostics --json | python3 -c "import json,sys; print(json.load(sys.stdin)['memory']['usage_percent'])"

# Check that the output is valid JSON
python3 -m linux_diagnostics --json | python3 -m json.tool > /dev/null && echo "valid JSON"
```
